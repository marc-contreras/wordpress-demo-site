# WordPress Elementor Portfolio Demo

Proyecto educativo realizado con WordPress + Elementor.

## Proyectos incluidos

### 1. Gym Landing Page
Landing page corporativa creada siguiendo un tutorial de Elementor.

Características:
- diseño responsive
- estructura moderna
- secciones reutilizables
- navegación optimizada

### 2. Parallax Demo Section
Sección experimental creada con Elementor Free usando efecto parallax.

Características:
- scrolling parallax
- superposición de capas
- efectos visuales sin código complejo
- optimización responsive

## Tecnologías usadas
- WordPress
- Elementor Free
- UpdraftPlus
- Astra Theme

## Funcionalidades configuradas
- backups automáticos
- restauración con UpdraftPlus
- diseño responsive
- export/import templates
